# Responsible use policy

ShopSphere exists to teach defensive and offensive web‑security skills in an
**authorized, controlled, educational** setting.

**You may:** run ShopSphere locally or on an isolated lab network; inspect its
source, traffic, and behaviour; perform security testing against its `/labs/*`
endpoints; use it in a classroom, CTF, or self‑study context.

**You must not:** expose it to the public internet; use it to attack systems you
do not own or lack written authorization to test; enter real personal data,
credentials, or payment information; reuse its intentionally weak code in
production.

All data shipped with ShopSphere is **fictional and synthetic**. Any resemblance
to real people, businesses, or payment details is coincidental. The techniques
demonstrated are for building secure software and conducting authorized testing
only.
